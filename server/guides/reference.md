# Working from a reference

## 1. Read it
`ae_reference {path}` gives size, fps, duration, frame grid, motion per interval, holds, cuts and brightness changes. For music, the same tool gives BPM and beats. Ask only what the reference can't tell you (text content, brand colours, logo files).

## 2. Beat sheet (write it before building)
For each element: what it is · enter time (s and frames) · duration · direction · easing feel (snappy = "snap"/"expo", soft = "smooth", playful = bounce) · exit. Note the rhythm: where the big motion bars are, where it holds, where it cuts. Palette from the grid (dominant bg, text, one accent). Type class (geometric/grotesk/serif, weight, case, tracking).

## 3. Rebuild
Match comp size, fps and duration first. Build in beat order. Rebuild the *style* — never copy logos, trademarks or footage from the reference; use the user's own assets or neutral placeholders.

## 4. Compare
`ae_review {reference: path}` (default 8 samples) → paired grid (ours | reference), layout similarity per moment, motion-rhythm correlation (aim ≥ 0.7 for "replicate"), and average colours. Fix the biggest gap first: timing (correlation) → layout (similarity) → colour → details. Two or three compare passes are usually enough.

## Improve mode
Keep the structure and timing that work, then raise the craft:
- replace linear or default easy-ease with designed curves;
- add hierarchy (hero first, supporting elements staggered 2–4 f);
- motion blur, subtle grain, slow push;
- sound design synced to hits;
- tighter type (tracking, weights) and a cleaner palette;
- remove anything that doesn't serve the message.
Explain the 3–5 most important improvements to the user in one short list.
